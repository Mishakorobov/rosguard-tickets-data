# 🛡️ Официальные билеты Росгвардии 2026 (ВОХР и ЧОП) — Data Repository

Публичный репозиторий эталонных вопросов периодической проверки и квалификационных экзаменов сотрудников ведомственной охраны (ВОХР) и частных охранников (ЧОП) 4, 5 и 6 разрядов на базе официальных регламентов Росгвардии.

Служит открытым CDN-источником автоматического обновления для мобильных приложений:
- **«Билеты ВОХР тесты 2026»**
- **«Билеты ЧОП Охрана 2026»**

## 🤖 Автономный робот-обновлятор (GitHub Actions)

В репозитории настроен автоматический пайплайн [monthly_updater.yml](.github/workflows/monthly_updater.yml):
1. **Периодичность:** Запускается **1-го числа каждого месяца в 03:00 UTC** (или вручную через `workflow_dispatch`).
2. **Проверка источника:** Сканирует официальный портал Росгвардии (`rosguard.gov.ru`).
3. **Валидация целостности:** Скрипт `scripts/verify.py` проверяет все вопросы, варианты ответов и ключи, предотвращая публикацию неполных или битых данных.
4. **Автокоммит:** При обнаружении новой редакции автоматически генерирует хэши SHA-256, обновляет манифест и публикует коммит в репозиторий.
